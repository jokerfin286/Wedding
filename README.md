# Wedding Invitation — editorial template

Современный адаптивный сайт-приглашение на свадьбу на React + Vite.

## Самое главное: где менять фотографии

Все изображения, которые используются на странице, находятся в одном месте:

```text
src/config/wedding.js
```

Ищите блоки с комментариями `ФОТО`.

### 1. ФОТО ПАРЫ — первый экран

Это самая важная фотография. Она показывается сразу при открытии сайта на весь экран.

```js
hero: {
  image: 'АДРЕС_ФОТО_ПАРЫ',
  label: 'WEDDING DAY',
  subLabel: 'Приглашение на наш особенный день'
},
```

Например локальный файл:

```js
image: '/images/hero.jpg'
```

Или внешний URL:

```js
image: 'https://example.com/my-couple-photo.jpg'
```

**Рекомендуемый формат:** горизонтальное фото 16:9 или 3:2, желательно высокого разрешения. Для первого экрана особенно хорошо подходит фотография пары, где лица находятся ближе к центру.

### 2. ФОТО МЕСТА ПРОВЕДЕНИЯ

```js
venue: {
  ...,
  image: 'АДРЕС_ФОТО_МЕСТА',
  mapUrl: 'АДРЕС_КАРТЫ'
}
```

`image` — фотография площадки.

`mapUrl` — любая ссылка на карту: Google Maps, Яндекс Карты, 2GIS или другой сервис.

### 3. ФОТОГАЛЕРЕЯ ПАРЫ

```js
gallery: [
  'АДРЕС_ФОТО_1',
  'АДРЕС_ФОТО_2',
  'АДРЕС_ФОТО_3'
]
```

Количество фотографий можно менять. Компонент галереи автоматически использует изображения из этого массива.

## Имена и дата

```js
couple: {
  groom: 'Александр',
  bride: 'Мария'
},

weddingDate: '2027-06-12T16:00:00',
dateText: '12 июня 2027',
```

`weddingDate` используется для countdown. Формат: `YYYY-MM-DDTHH:MM:SS`.

## Музыка

```js
music: {
  enabled: true,
  src: '/music/wedding.mp3',
  title: 'Our song'
}
```

Автовоспроизведение не используется: музыка запускается только после нажатия гостем.

## Запуск

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

После сборки папка `dist` готова для размещения на статическом хостинге.
