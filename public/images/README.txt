КАК ДОБАВИТЬ СВОИ ФОТО

1. Положите фотографию пары в эту папку и назовите, например, hero.jpg.
2. В src/config/wedding.js укажите:
   hero.image = '/images/hero.jpg'
3. Фото места можно назвать venue.jpg:
   venue.image = '/images/venue.jpg'
4. Фотографии галереи:
   gallery: ['/images/couple-1.jpg', '/images/couple-2.jpg', '/images/couple-3.jpg']

Можно вместо локальных файлов использовать прямые URL.
